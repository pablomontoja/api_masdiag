# Phase 1 Data Model: Ruby 3.4 Upgrade

**Feature**: 008-ruby-34-upgrade | **Date**: 2026-08-17

## Scope note

This change introduces **no database entities and no schema changes** (FR-010, SC-005). It touches
no application code at all. The "entities" below are the **verification records** the change
produces to satisfy its own auditability requirement (FR-020) — documents, not tables.

---

## E2 — Undeclared Standard Library Finding

One per stdlib component that code loads without declaring it. This category is the entire
substance of the feature.

| Field | Description |
|-------|-------------|
| `component` | Standard library name |
| `required_by` | File(s) issuing the `require` |
| `declared` | Whether it appears in the `Gemfile` |
| `status` | `already-declared` / `needs-declaration` / `confirmed-unused` |

**Known state entering execution** (FR-002 requires re-scanning, not trusting this):

| Component | Required by | Declared | Status |
|-----------|-------------|----------|--------|
| `csv` | 6 files (5 MasdiagRecurring mailers + `CeraStatisticCreator`) | ✅ | already-declared — spec 007 |
| `base64` | `ScannedDocs::OcrClient` | ✅ | already-declared — spec 007 |
| **`observer`** | `factory_bot-4.11.1/lib/factory_bot/evaluation.rb:1` | ❌ | **needs-declaration — this feature** |
| `ostruct`, `bigdecimal`, `drb`, `logger`, `benchmark`, `mutex_m` | none in project code | n/a | confirmed-unused (present transitively only) |

**Impact if missed**: the application fails at boot with `cannot load such file -- observer`. All 97
load errors in the sandbox trial traced to this single omission.

## E4 — Runtime Version Pin

The version is declared in three places plus the lockfile; all must agree (FR-005, SC-006).

| Location | Current | Target |
|----------|---------|--------|
| `.ruby-version` | `ruby-3.3.7` | `ruby-3.4.10` |
| `Gemfile` | `ruby "3.3.7"` | `ruby "3.4.10"` |
| `Dockerfile` | `ARG RUBY_VERSION=3.3.7` | `ARG RUBY_VERSION=3.4.10` |
| `Gemfile.lock` | `ruby 3.3.7p123` | regenerated by `bundle install` |

**Failure mode if they diverge**: works locally, fails in the deployed image — the drift is invisible
until deployment.
